# atu's Homebrew tap

```bash
brew install --cask atuuuuuuu/tap/convrt    # hold Shift while dragging a file to convert it
brew install --cask atuuuuuuu/tap/scrollr   # reverse your mouse, keep your trackpad
```

| Cask | App |
|------|-----|
| `convrt` | [Convrt](https://github.com/atuuuuuuu/Convrt): offline file converter in the menu bar |
| `scrollr` | [Scrollr](https://github.com/atuuuuuuu/Scrollr): natural scrolling for the trackpad, normal scrolling for the mouse |

Neither app is notarized yet. The first time you open one, macOS may block it: go to
**System Settings → Privacy & Security** and click **Open Anyway**.
